# 车端控制隔离实施计划（2026-11-16）

本次仅实施用户已填写第2—6项；原始观测、感知与指令期限保留，各静态模型启动租约删除。命令入口只保留来源、幂等、连接代次与显式急停交付；运行报告无运动准入期限。

- `SafetyGate` 是唯一 ROS 速度发布与 MotionStateMachine 内存 owner，专用进程按单调时钟20Hz执行，只有一个在途 tick。绝对槽位调度：完成后跳过已错过槽位，不追赶；控制器使用实际 dt，非法/倒退时钟仍拒绝。
- 独立 spawn 接收/估计进程拥有 native receipt 接口、轮速/IMU/可选观测接收和扫描准入。将一致输入状态序列化为有界最新快照交接，原采集/接收时间与期限不刷新；没有无界消息队列，读写不等待忙锁。控制进程读取一次快照后独占该本地副本。
- 独立 spawn 几何进程处理方向细化，最多一个在途任务与一个可覆盖待办。结果保留身份、版本、期限，由当前快照重新收紧；过时结果丢弃。接收不受 Python GIL 或几何锁串行影响。控制快速核验仍可能占用本轮预算，其耗时必须在统一验收测量，不能宣称硬实时。
- 运行报告从最新输出投影独立发布，不被入口用于复刻控制资格。日志/任务/视频在其他进程；控制不等待云回执。原本本地输出通道兜底保留，物理 watchdog 时限待现场核实。
- 单一静止实现仅消费真实轮速纵/角速度与 IMU 角速度；复用现有 profile 的静止阈值，缺失、非法或到期样本不当零。急停复位、故障恢复、学习和模式转换共享此证据，独立平移观测不参与静止资格。

生命周期：父进程启动接收进程及几何 worker，快照槽预分配固定容量；初始化失败撤销输出。关闭时先停止运动/撤销目标，再通知子进程退出、有界 join，必要时 terminate/kill 并 join，关闭 IPC；不重启以恢复旧目标或旧学习动作，不恢复软件急停文件。

本阶段不改测试、不运行套件/ROS/服务/车辆。统一测试需迁移已删除字段及入口资格断言，覆盖0→80→100ms槽位、长期运行、几何饱和/接收并行、快照过期/来源换代、轮速IMU静止与缺失/运动、急停复位/故障恢复/学习撤回、手动断流与任务生命周期。交付仅为代码修改完成，统一测试待执行。

## 最终接线补充

最终决策及软件急停 owner 仍为 `safety_gate` 内的 `MotionStateMachine`；`motion_output_guard` 是其私有、无锁存的唯一 `/cmd_vel` 发布传输，按决策原证据期限归零，EOF 归零并退出。`motion_reporter` 独立持续发布最后已知投影，保留原采样时刻，命令节点只认证来源及序号，不以报告准入。

硬件及仿真 launch 移除不再被控制器消费的独立 `motion_fusion` 节点；轮速 frame 配置迁入 safety_gate，实际 `/odom` 和 `/imu/data_raw` remap 明确传给接收子进程。旧配置仅迁移 wheel frame（标注 Compatible），没有保留模型租约或旧报告期限空壳。

扫描预处理在控制槽之间预取；射线过滤、free-patch/union 计算及方向细化各占独立进程。严格按扫描、坐标代次及完整过滤模型版本丢弃过时结果；来不及产出对应结果时归零，不把计算 pending 当传感器丢失去关闭仍有效目标。控制槽内保留最终空间误差收紧、粗停车/输出证书核验，这些有界 GEOS 调用及快照序列化仍可能耗时；未测得其最坏耗时，不能称为硬实时。持续高频扫描、慢预处理下的有效输出可用性是统一验收重点，不能用延长旧证据期限消除 pending。

进程正常退出使用 ExitStack 逆序释放；spawn 子进程在 Linux 注册无需 root 的 parent-death signal，并核对注册竞态。关闭先撤销并发送零，再有界 join/terminate/kill；原生输出通道 EOF 停车不依赖 Python GIL、云端或报告进程。
