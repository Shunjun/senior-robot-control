## 架构选择（协调者准予实施）

推荐保留现有纯数据契约和 ROS 适配能力，**将唯一 `MotionEstimation` owner 放在 safety_gate 输出组合的控制周期内**：原始来源适配后 `ingest()`，每 tick 只调用一次 `estimate(T)`。这样某个旧贡献者在 1 秒边界过期时，同 tick 会重算剩余有效源，不因跨进程旧融合快照的最短 deadline 把其他活源一并停掉。

`NativeObservationRosBridge` 拆成只负责真实来源/原始时间/坐标输入的 facade，通过注入回调接该 owner；不再在 motion_fusion 和输出层各运行一个资格/融合 owner。旧 motion_fusion 的 progress/诊断如仍被导航使用可继续产出，但不得作为第二条驾驶测速资格链。规范化估计可发布给其他只读用途，发布者心跳不是样本新鲜度。

不推荐继续保留现有多层挑源后仅放宽常量（仍有矛盾 gate），也不推荐重写传感驱动/所有导航（超出所需）。若协调者希望继续将 owner 放在独立进程，需要先解决上述分量过期、快照重算和控制消费的接口，而不能把单个贡献者 expiry 直接等同全反馈丢失。

按职责组合，禁止一个大函数包办所有物理量：

| 模块/拟定接口 | 独占职责 | 不负责 |
| --- | --- | --- |
| `SensorTiming.classify(origin, now)` | 同一时效定义和原始时间账本；.3/1 唯一参数源 | 手动授权、避障决定 |
| `MotionEstimation.ingest(sample); estimate(T)` | 分量对齐、去重、冲突、一致组、当前 vx/vy/wz | 独立停车包络、执行器输出 |
| `PoseEstimation.ingest(pose); at(T, motion_history)` | 位置/朝向融合及 SE(2) 历史/预测、误差 | 不将外推当新绝对观测 |
| `SpaceEstimation.ingest(evidence); at(T, pose)` | 同坐标/时间的占用、可通行区、未知、关联障碍 | 不平均不同障碍、不由缺测产生空闲 |
| `RuntimeDiagnostics.observe_age/observe_queue; flush(now)` | 有界年龄/等待/耗时统计、统一限频告警 | 不授予或撤销驾驶资格 |

## 时间契约与唯一参数

拟新增 `config/sensor-policy.defaults.json` 作为软件默认唯一数值源，显式加载为 `SensorTiming`；Python、launch、C++ sensor receipt 共用一次解析后传入的同一组值，不分别手写 .3/1。全环境默认 `soft_age_s=.3, hard_age_s=1, diagnostics_period_s=5`；可配置时全传感器共享，校验 `0<=soft<hard`。不增加驾驶 UI 参数，不修改已运行车辆配置。

每个原始根记录 `source_id/instance, epoch, sequence, sample_ros_ns, received_ros_ns, received_steady_ns, lineage`；处理时刻另列 `computed_at`，不得覆盖任何原始时间。对 interval/rate/delta 保留 `[start,end]`，值的代表时刻 `t_i=(start+end)/2`，点样本为其原始观测时刻。派生结果保存所有实际参与观测的根；不重复插入派生“新样本”。

在本机首次接纳，冻结 `initial_age=max(0, received_ros-sample_ros)`；当前根年龄 `a=max(T_ros-sample_ros, initial_age+T_steady-received_steady)`，非法未来时间/倒退/跨 epoch 另处理，不把负年龄夹成新鲜。interval 若由两帧产生，两个原始 capture 均进入根账本；该候选时效取所需动态根年龄的最大值。代表时刻负责对齐，原始根时刻负责时效，二者不可混淆。静态外参/标定是配置代次，不是每秒必须重发的动态观测。

有效根 `a<1`，等于 1 已过期；复算/转发/外推/统计 flush 均不能延寿。ROS 暂停时 steady 年龄仍走，不再于暂停 .3 秒提前中断；真实时钟倒退建立新时钟代次并隔离旧样本。迟到乱序不能覆盖本来源更新样本，但可计诊断。

来源真实性、消息结构/有限数值、有效标志与年龄是不同维度。结构错误可立即拒绝该数据；某一路状态变化只中断该路，不能抹掉其他来源。恢复计数可用于可信等级/显示，不再把 5 份/0.5 秒当首次使用单一有效来源的门。软件/硬件急停、显式执行故障复位仍按独立状态机，不由新估计自动清除。

## 具体分量算法

### 1. 规范化、依赖与时间对齐

每来源每分量最多一个最新候选。转换到 body 速度、ENU/odom 位姿等目标物理量，无法转换的分量明确 unavailable，其他分量继续；不比较坐标系不同或不同对象的数据。对 wheel(vx,wz)、gyro(wz)、laser/RGB-D delta(vx,vy,wz)、GPS 原始速度/位置按实际支持维度接入。现 ROS bridge 未接 GPS，计划提供可选已声明 topic/坐标/heading 的适配，不伪造已安装 GPS。

统一比较时刻为本 tick `T`，不等待所有传感器凑齐 laser 窗。点速度先用该来源自身最近两个合格历史样本斜率估计加速度，按现有模型的允许幅值夹紧，再外推 `z_i(T)=z_i(t_i)+a_i*(T-t_i)`；历史不足用 ZOH。interval 用中点均值作同样因果近似，同时记录半区间误差。**不使用未来观测插值，不用命令速度作传感器票，不用外推后的 T 比新鲜度。** 新旧历史都必须为合格原始输入；斜率历史过期则回退 ZOH，不让较新速度也失效。

对齐误差提案 `e_i = e_sensor_i + A_k*(T-t_i + interval_half_width)`；只是当前误差估计/配置包络的账本，不将其称作测量保证，也不修改排队的停车包络算法。无已知误差模型时标 unknown，仍以较低质量参与控制估计，不要求有可信统计协方差才可加权。

根去重按“同一物理来源/原始采样 lineage”而非 topic 名：同一 odom 派生的 twist、delta、重发布只能一票；融合输出不得回灌为新独立票。一个多源派生候选与其原始分量同时存在时优先原始，不能同时投票；仅有派生结果时其共享根组保守计一票。坐标变换的共同 heading 是辅助误差依赖，不额外贡献一张线速度票；标出相关性，不能据票数缩小物理误差。每轴最多 8 个独立来源组，全部子集至多 256，配置超过容量明确报配置错误而非无限枚举。

### 2. 一致阈值、质量与权重（数值为获准实施的软件初始参数，非实测）

拟采用共同默认基础容差：`tau_vx=tau_vy=.10 m/s`，`tau_wz=.15 rad/s`；位姿关联另用 `.10 m`、`.10 rad`。理由：已有 conflict 配置硬件来自 `2*linear_error / 2*yaw_error`，仿真为 `.4/.2`，没有一套获实测证据的通用阈值；因此明确提出可调软件容差，**不是**把旧假设升格为已验证物理值。所有环境共用默认与单位，后续可由留出数据校准，不能为了通过数据自动扩大阈值。

两对齐候选一致条件：`abs(z_i(T)-z_j(T)) <= tau_k + min(e_i+e_j, tau_k)`；误差 unknown 时附加量取 0、质量再乘 .5。附加量最多一个基础容差，防止旧观测靠不断膨胀误差把所有异常包成一致。

质量 `q`：有规范化生产者质量则使用；没有质量但值有效取 `.5` 并标 unknown；`drift` 警告乘 `.25`；明确 unavailable、q=0 不投票，NaN/越界质量为数据错误。无 covariance 不拒绝；非法可选 covariance 不参与误差/权重，并降可信，必需 payload 结构错误仍拒绝对应数据。

新鲜度权重 `f(a)=1 (a<.3)`；在 `[.3,1)` 为 `.1 + .9*(1-a)/.7`，在 1 为 0 并无效。连续下降，不在 .3 硬拒绝或骤停。权重 `w_i=q_i*f(a_i)/(1+(e_align_i/tau_k)^2)`，unknown 误差按前述质量降级，未知不当成已知 0 误差证据。用最大权重缩放再归一化，避免极小正质量数值下溢。结果是控制参考权重，不宣称高斯最优或独立安全保证。

输出可信度提案也明确数值：令归一化权重为 alpha，`C=sum(alpha_i*q_i*f(a_i))`；有获选低可信年龄源时上限 `.6`，有离群剔除则再乘 `.75`，无法归因的冲突平局/无一致组取 `min(.2,C*.5)`。单源正常时 C=q*f，不因缺其他源变无效；这个分数不是概率，也没有“C低于某值就禁行”的额外门。结果误差账本在全部已知时取 `max(e_i+abs(z_i-result))`，不按票数开方缩小；任一必要项未知则保留 unknown。独立停车包络继续消费原有能力声明，不把本经验分数/误差当作物理保证。

### 3. 冲突、一致组与确定平局

- 一个有效候选：直接用它；标 single/low 或正常可信，不因没有第二/第三路失效。
- 两个且一致：归一化权重平均。
- 两个且冲突：用**代表原始观测时间**较新者；即使旧值质量更高，也不把大差异平均到中间。相同原始时间时按 `q` 高、对齐误差小、固定 source_id 字典序依次决胜，结果标 `conflict_unresolved` 且 confidence 不超过 .2；不清空双方后禁行。
- 三路以上：建立两两一致图，枚举最大一致 clique。优先独立组数最多的组；同大小按总权重高、组内最新原始时刻新、source_id 稳定顺序决胜。只在获选组内加权，其他离群只影响诊断，不能反过来否决该组。A近B、B近C但A远C不能链式算三者一致。
- 没有大小>=2的一致组：退回单个最新原始候选；同时间平局规则同上，标 unresolved/低可信，而不是随意平均三路或全拒绝。
- 上述每轴独立执行。角度需先相对最新 heading 解包到同一分支，比较最短角差，再平均并 wrap；wz 本身是有符号角速度，不做 2π wrap。

### 4. 输出、缺分量与控制消费

`MotionEstimate` 输出 T、vx/vy/wz 的 `value, observed, confidence, age_state, raw_times, roots, reason, independence_kind, error`，以及 next_source_expiry、clock/source generation。每次控制 tick 用唯一 owner 重新估计；一个过期贡献者移除后立即用剩余有效者，不把 min(deadline) 过期等同全部无反馈。

vy 无有效观测：`value=0, observed=false, reason=assumed_zero_lateral`，不入权重、不入独立源数，不让 vx/wz 的 observed/status 下降。vy 有实测时使用实测；不能给默认 0 伪造小方差/真实侧向保证。

vx/wz 缺一个时该分量输出 `observed=false`，保留“估计值缺失”与“控制所需数值”区别。提案控制层该轴关闭 PI，用既有轨迹模型做有界 feedforward，`model_only` 标记，**不作为传感器票或独立真速**；仍有有效相关实测分量时继续受限控制，不能强制 wheel+IMU 或三个分量齐全。全部相关实测 vx/wz 来源因年龄到 1 秒均失效（或确实无有效数据）才触发无反馈受控制动，模型不续命。此逐轴 fallback 已获协调者批准，缺轴仅可在自身原始证据硬截止前短时使用模型；另一轴不能续命。这是明确实现决定，不能暗中把缺 vx/wz 设成实测 0。

下游 controller、runtime、manual acquire、navigation 消费统一结果，不再次比较原始 wheel-vs-body 差异，不检查原始源组合，不重新设 .15/.3/.5 的测速期限。显式 execution fault 仍可依据独立、持续跟踪失败证据触发，不把普通传感器冲突换名为故障。

模式只描述证据：独立线速度可用=reference；仅轮式/模型主导=degraded；没有相关实测=unavailable。至少 .3 秒的低可信、冲突或来源切换可收紧可信度/积分权重，目标仍经过现有 jerk/加速度轨迹；不得重置轨迹为零或从旧按住动作复活 authority。手动 `.3 m/s` 保存设置继续控制退化满杆；导航策略保持此前分工。给停车包络消费者的独立体运动证据单列，轮速/模型不能填到 independent_body 字段。本轮不改变独立停车包络公式；若原包络因此仍不能为某场景形成许可，应如实回报为排队项依赖，不能用估计层再加拒绝掩盖它。

软年龄到 .3 不发 FEEDBACK_LOST、不清 authority、不要求松杆重申请；真正全相关源失效才走既有反馈失效/重新输入语义。来源恢复/变化也不能清已有独立故障或急停。

## 位姿、障碍与可通行空间

位姿 owner 对已有历史同 epoch 插值；最新绝对姿态较旧时，用有效运动估计的 SE(2) 积分外推到目标时刻，保存原绝对观测时间、运动 lineage 和累计误差。不同定位源须同 frame/地图版本、同时间才按同物理量的一致/冲突规则融合；导航/map坐标代次不同不能平均。绝对来源到 1 秒硬失效后，不再叫“新鲜绝对位置”，但可继续输出明确标记的相对 dead_reckoning；误差随积分累计，不因每次外推清零。GPS heading/lever-arm 等只能用真实对齐依据，缺该变换只影响不可转换分量。

空间 owner 将雷达点、深度/语义障碍按观测时刻的 pose 和外参转换到同一参考时刻/坐标，结合位姿/运动误差扩大占用、收缩 free-space。先关联“同一物体”：已知 track_id 或在同 frame/类别/时间中通过距离和不确定性门的匹配；不同障碍保留为不同对象，不能把左右两障碍平均成中间一个。关联失败保留占用并集，不删除不确定对象。共享来源重建/重发布不重复增强可信。

关联的具体保守提案：同一全局 track_id 可关联（来源局部编号不能直接当全局编号）；否则仅当同类/类别不矛盾、投影形状 IoU>=.5、中心距离 `<=tau_position+min(u_i+u_j,tau_position)` 且互为唯一最近匹配时才建立候选关联。多解、误差unknown、无形状点障碍只保留占用并集，不平均中心；出现关联歧义撤销关联，不删除物体。这些阈值是待审软件策略；匹配出的中心即使可融合，也不缩小已观察占用范围。

同一对象位置冲突按前述规则选择估计中心，但冲突占用范围保留两候选可能范围，不能用选中心消除已见障碍。可通行区来自有效观测 free-space 的并集，扣除所有有效占用及必要遮挡/不确定区；没有观测的单元是 unknown。稍旧的合法证据按误差和可信度折减，不单独因 .3/.5 秒拒绝整个空间结果；到 1 秒撤销其正向 free-space 贡献。模型预测障碍可保留占用记忆，不能刷新原始传感器年龄。确实无法证明所需扫掠可通行时保留原避障制动，这是结果不支持用途，不是“某一路没来”资格门。

## 实施落点与方案取舍（2026-11-15）

唯一运动 owner 已落在 MotionCoreOutput；MotionSensorRuntime 只组合原始适配、MotionEstimation、PoseEstimation 与诊断。motion_fusion 的历史 progress/诊断仍保留，未注册其融合快照为驾驶输入。当前 SpaceEstimation 采用显式 frame/pose/epoch 的几何变换、有效占用并集与 free-space 扣除占用；没有新增全局对象追踪器，也未实现上文作为候选提出的 IoU/最近邻中心关联。该保守取舍避免把不同物体平均，缺测不产生 free-space；上文 track 匹配数值不是现有产品能力声明。

运动/位姿误差未知时保持 unknown，不把权重或软件误差上界当作物理认证。可配置 GPS 明确要求 raw origin_family 和真实坐标变换；RGB-D 只作为统计运动候选，既有硬物理误差标记仍为 false。ScanMotion 新增 first_capture/second_capture，原始两帧接收延迟不能被匹配完成时间刷新。部署依赖同版 ROS 消息生成及所有原生/适配消费者重建。

独立停车包络保持原算法，可能仍限制仅轮速/部分分量场景的最终通行；本轮干净估计接口不等于其许可修复已完成。具体命令、回归与 Draft 缺口见[实现报告](../../testing/2026-11-15-unified-estimation-implementation.md)。
