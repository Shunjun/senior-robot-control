# 随车回波：稳定连续表面与固定1cm过滤

状态：2026-11-16 用户最终批准，产品已返修，集中验证与限制见新的固定参考测试报告；旧测试报告仍只证明其历史版本。此前严格内部排除车外部分、世界固定反假设、位姿积分及运行期撤销设计均由本节替代。

固定0.05m/s、host steady 3秒动作期间，根据每帧实际角度和距离转换的雷达/车体相对端点比较位置；同一参考位置在每个接纳帧的回波云中均须有硬编码1cm以内支持。支持可来自邻近方向，不要求角度、浮点坐标或数组序号逐帧完全相等。不计算车辆前进距离，不以世界坐标反假设或精确独立位移作学习条件。

同一扫描中相邻有效命中点连续组成离散段；包含实际车体内部回波的段可向车外延伸，无效/缺失/非命中束或缺失序号中断连接。完整360°扫描按实际采样拓扑连接首尾，支持周期采样和重复端点两种表示；局部扫描不跨端点连接。不新增欧氏连接距离、角度阈值或亚束实体填充证明。候选在各学习帧都要同时满足位置稳定及上述连接规则；中间回波不稳定剔除后，以剩余稳定支持重新分段和检查车内连接，失去连接的外侧片段也删除，有其他稳定车内连接路径的部分保留；无需证明物理同一物体，不能再因远墙可能邻接或激光离散性额外拒绝已批准的离散判据。实际车体内部是连接种子，不能继续作为所有候选或运行期端点的边界裁剪。

参考点取自学习实际观测，学习期间固定参考坐标并逐帧求稳定候选交集；至多2048个初始候选，最终保存全部稳定候选（最多2048点），不以stride抽样丢失已学表面。近期64帧采集身份有界保留，但早期帧对候选交集的影响不能因窗口滚动丢失；已丢弃身份由原采集前沿拒绝重放。来源/物理时钟轴变化仍分段，ROS标签跳变不替代源采集时间。3秒动作从首次成功提交非零私有输出起算，沿用动作结束和停车后新帧的生命周期确认，停车后帧不再核验或删除3秒期间采集的候选。

学习完成后保存并冻结参考位置。正常运行只读完成模型，当前命中点距任一参考点不超过1cm即直接标记self；缺帧、无匹配、遮挡、手挡后拿开均不修改参考位置。未匹配点保留既有普通扫描处理；不将整束其他距离或整个扇区当作self，不按物体身份重验，不把未观测方向当作自由空间。只有将来明确重新学习才替换结果，本次不新增重新学习入口。

sensor_error/orientation_error_rad继续承担既有外部避障预算，不参与学习模型或1cm过滤；1cm是用户位置匹配政策，不是传感器实测精度。浮点边界只允许数值表示舍入保护，不增加物理容差。
