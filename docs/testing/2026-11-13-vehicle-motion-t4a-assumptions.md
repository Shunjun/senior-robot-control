# T4a模型/几何假设与T5验证边界

本页仅描述纯算法证明的条件，所有定向测试profile均synthetic，不能发车。

| 条件 | 当前实现/后续责任 |
|---|---|
| 车体 | 提供以body原点为中心的外接矩形，含真实附件；长宽乘1.05一次。当前物理足迹必须已知非穿透障碍，不能由scan缺回波推断。T5/fixture核对尺寸、坐标、外参。 |
| 独立当前能力 | RiskEnvelope的signed vx/wz范围、反应期间最大向外加速度、整时域位姿误差、侧滑及settling必须有独立basis、scene/mode/epoch/profile scope和有效期。固定profile参数不等于固定零速度状态；每个快照必须提供对当前状态/已执行控制成立的范围。不得从未知统计P、轮速任意±常数生成它。BodyMotion.upper存在时只作为额外交集。 |
| 停车响应 | SI单位，ResponseBounds为加速/减速/jerk及延迟；S曲线考虑反应期间加速度及释放后的速度超调，终端速度和加速度归零。命令与执行器必须服从有限、无额外超调的已验证响应族。T5轨迹、PI/饱和、watchdog与真实减速能力需要验证；当前仅数学积分，不允许默认反向制动。 |
| 平移/旋转 | 旋转包络加signed平移可达域的保守Minkowski和覆盖变化曲率、原地旋转及复合目标，不分别限轴后直接授组合。快路径用解析外接域，慢路径有限角度步数。它可能过保守；不得据此声称所有狭路可通。 |
| 感知 | 原始free patches是经外参变换、self-filter/depth处理后的真实可观测凸区域；unknown/no-return默认未知。传感定位误差只在预处理free收缩/hit扩张一次，不再加车身；航向误差计入平移方向一次。physical与padded新扫掠都须可观测，不能把旧padding盲区当车身。 |
| 动态场景 | free/occupied几何须支持从原stamp起forecast_horizon内障碍可达预测；本阶段静态合成场景可以此声明。真实动态障碍的速度/可达集合尚未实现，不能用静态点的长预测域生产放行。没有合格方向观测则受控制动，不是永久急停。 |
| 时间/预算 | 原steady感知/运动deadline不重盖；风险/响应和预测覆盖直到停车完成。候选最多16，观测复杂度/角步数/worker预算显式注入。测试为4候选、yaw步.05rad/128步、观测8patch/64vertex/64hit、lease1s；不是Linux实时边界。 |
| 退化与恢复 | upper/完整average可空，轮+IMU限速模式只有独立适用风险域才可证明几何，缺域返回未验证受控制动请求；模式cap下降只收紧，恢复平滑归T5，T4不发运动许可、不新增源健康owner。 |
| T5输出 | 先满足轨迹jerk/加速度/换向可实现性，再逐次调用validate_output；较小插值必须重新证明，不能从两个轴或离散端点自动继承许可。BrakeRequest的stop_verified是条件模型下几何证明，不是传感器确认车已静止。紧急制动请求不等于用户/硬件ESTOP。 |

独立仿真固定profile的后续验收必须测车体truth、轮速/滑移、响应滞后、jerk停车、偏航和漂移、观测误差/动态障碍及Linux最坏tick成本；适用域外返回原因并制动，禁止看完结果调通过线。真实硬件、5 km/h闭环、29项冻结和在线自适应均未由T4a完成。
