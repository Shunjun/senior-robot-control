# 实车验收清单

本清单与仿真验收分开。只在低速、封闭受控场地，由一名操作员和一名现场安全员执行；物理急停始终可触及。仿真参数、示例制动值和未核对的话题不能直接用于实车。

## 进入场地前

- [ ] 记录代码版本、车辆编号、固件、OS/ROS 版本、配置哈希和日志目录。
- [ ] 核对厂商底盘、雷达、相机、IMU、编码器的话题与坐标系。
- [ ] 标定车体外形、自遮挡区、线速度/角速度上限和制动距离。
- [ ] 验证物理急停可独立切断驱动，安全员完成口令确认。
- [ ] 架空车轮确认方向、编码器符号和 `/cmd_vel` 唯一发布者。

## 低速静态检查

- [ ] 无命令、命令过期、网络断开和车端进程退出时保持停车。
- [ ] 扫描、TF 或感知过期时安全门保持停车。
- [ ] 急停锁定后，普通驾驶、导航和脱困命令都不能恢复运动。
- [ ] GPS 和被动航向输入不产生速度命令。
- [ ] 网页缓存状态不能获取控制权或发送导航目标。

## 低速运动检查

- [ ] 在空旷区逐步验证前进、后退、左转、右转及松手停车。
- [ ] 测量实际制动距离并更新硬边界，保留原始测量日志。
- [ ] 靠近墙体验证预测扫掠停车，全程禁止接触。
- [ ] 后部遮挡时只允许有界、地图辅助倒车；实时障碍立即否决。
- [ ] 狭窄走廊中保持低速，定位不确定时停止导航。
- [ ] 人员进入视野时不写入长期占据层，人员离开后不留下持久障碍。

## 状态与恢复

- [ ] 断线中的任务停止；重连后不自动恢复或补跑。
- [ ] 重启后 Home 保持原值，返航前人工核对地图引用。
- [ ] 有 GPS 和无 GPS 的地图导入都完成可靠匹配；跨车 Home 保持待确认。
- [ ] 损坏地图包、GPS 跳点、时钟回退、视频拥塞均不绕过安全链。
- [ ] 每项结果都附日志以及对应截图/录像；缺失产物时该项保持未勾选。

## 退出条件

- [ ] 全部异常均有停车证据，且没有未解释的速度发布者。
- [ ] 所有失败或未执行项已登记负责人、复现命令和后续计划。
- [ ] 安全员与操作员共同签字，记录日期、场地和车辆状态。
