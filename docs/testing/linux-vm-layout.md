# Linux 虚拟机测试目录

本项目在虚拟机上的代码、测试环境、构建产物与审计记录统一放在：

```text
/home/toby/senior-audit-20261031/
```

当前 RGB-D 开发继续使用 `author-d2a-tdd/`；控制方独立原生构建复用 `d2a-native-root-v2/`，其中 `v3-*` 日志表示在同一个构建目录复测第三份冻结源码，并非新增散落目录。已有的历史冻结版本保留用于回溯，不在测试期间搬移或覆盖历史日志。

每个测试工作区内部使用 `src/`、`build/`、`install/` 与有明确名称的日志文件。Python 环境使用统一根下现有的 `.venv*`，不向系统 Python 安装测试依赖。

所有后续 ROS 测试应显式将 `ROS_HOME` 与 `ROS_LOG_DIR` 设为统一根或该测试工作区的 `ros-home/` 及其 `log/` 子目录，避免使用默认用户日志目录。不要擅自清理用户原有的 `~/.ros`。

虚拟机构建和测试共用根目录下的 `.vm-test.lock` 串行执行；独立复测读取冻结源码并核验文件摘要。启动仿真、ROS 节点或网页服务仅用于有界调试和测试，结束后必须检查并回收相关进程组。
